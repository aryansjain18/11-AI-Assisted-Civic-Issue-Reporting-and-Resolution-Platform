# 11 — Definition of Done

A feature is complete only when all applicable checks are satisfied:

- [ ] Meets the documented requirement and challenge traceability entry.
- [ ] Works in the intended user flow.
- [ ] Has appropriate loading, empty, success, and error states.
- [ ] Validates untrusted input at the trusted boundary.
- [ ] Enforces authorization server-side.
- [ ] Has tests for normal, invalid, and unauthorized cases.
- [ ] Is keyboard-operable and has accessible labels/focus behavior.
- [ ] Works at mobile and desktop viewport sizes.
- [ ] Does not introduce avoidable console errors or warnings.
- [ ] Does not add unnecessary dependencies or expose secrets.
- [ ] Documentation and `PROJECT_STATUS.md` are updated.
- [ ] Relevant checks were actually run and results recorded.

If a checklist item does not apply, explain why.
